# OpenStudyHub 3.2.1

A small fix for the AI assistant introduced in 3.2.0. Use the pinned `ghcr.io/richardspinola/openstudyhub:3.2.1` image.

## Fixes

- The AI workspace now uses the full width of the screen on large displays instead of the centred Extras column.
- The blurred wallpaper now shows behind the AI workspace, with the assistant panels frosted like the header. Other Extras tools keep a plain background.

## Updating

No database changes. Update from 3.2.0 by switching the image; from older versions, follow the [update guide](docs/backup-update.md).
