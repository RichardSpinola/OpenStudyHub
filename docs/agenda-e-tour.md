# Personal planning and guided tour

Your personal tasks and calendar complement the academic timetable; they do not change an institution's class schedule or coursework deadlines. Open the planning tools, create a task, set its date and update its completion state. Use calendar views to relate your own tasks to academic commitments.

## Guided tour

The tour introduces the actual screens in sequence. New users can follow it, skip a step or leave. Existing users can reopen it from Settings → Help, so joining before an update does not prevent learning the current interface.

The invitation and completion state avoid repeatedly forcing the same onboarding. The administrator controls the instance's tour invitation. The tour is a guide to using the product, not a changelog or a claim that the person has already used each feature.

Need a specific action? Use [workspace](workspace.md), [notes](notas.md), [library](library.md) or [settings](configuracoes.md) instead of restarting the entire tour.
