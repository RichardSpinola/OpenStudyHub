# Legacy import classification reference

This compatibility reference classifies all 68 main-database tables: 52 legacy tables and 16 workspace additions. It guides the canonical importer; it does not authorize importing real data.

`MIGRATE` retains records with ID remapping. `TRANSFORM` requires model/column conversion. `SKIP/RUNTIME` recreates temporary state. `REVIEW` requires an explicit policy or human decision. Table identifiers, category values and their order are parsed by the runtime and must remain stable.

## Import order and safety

Start with a consistent backup and verified source restore, then an empty disposable canonical target. Import safe user/settings data, academic structure/curriculum, enrollments, content/assets, explicit shares and optional Chat. Produce counts, orphan references, asset hashes and skipped-item reports. IDs are mapped per table with batch transactions and checkpoints; a retry starts from a disposable target, leaving the source intact.

The 16 workspace additions are optional when examining an older source. Unknown tables still block import. REVIEW decisions, ambiguous curriculum terms and cohort conflicts require human resolution. Similar names must never silently promote Google integrations. This is a legacy import policy, not the ordinary V2 → V3 in-place update procedure.
