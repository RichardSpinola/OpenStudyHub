# Modelos de documentos

Modelos oferecem um formulário para documentos repetíveis. São diferentes dos modelos de páginas de Notas e não copiam suas notas para Google Docs.

## Use um modelo

Abra Biblioteca → Documentos → Criar documento, escolha o modelo e preencha os campos. Confira título e associação antes de gerar. A geração Google depende do Drive central pronto. Um modelo remoto ausente não é recuperado repetindo o formulário.

## Traga seu modelo

Use a importação de DOCX ou, quando configurado, selecione um Google Doc existente pelo Picker. Expanda a importação Google Docs somente ao usar esse caminho. Uma URL colada não autoriza documentos arbitrários com `drive.file`.

Dê nomes reconhecíveis, use a sintaxe de campos/placeholders apresentada no formulário e confira os campos detectados. Gere um exemplo antes de compartilhar amplamente. Os DOCX genéricos distribuídos ficam em `docs/examples/document-templates/`; o manifesto descreve o conjunto inicial. Eles contêm conteúdo fictício.

Modelos privados ficam na pasta com nome da pessoa, dentro de Modelos no Drive configurado. Compartilhar modelo, usar documento gerado e conceder edição Google são ações separadas. Veja [Google](google.md) e [Biblioteca](library.md).
