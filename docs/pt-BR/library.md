# Biblioteca, documentos e projetos

A Biblioteca separa **Documentos** e **Projetos**. Use Todos, Meus conteúdos e Compartilhados comigo para localizar itens. Filtre por nome ou disciplina e escolha lista ou grade. Projetos arquivados têm uma entrada própria na navegação de conteúdos.

![Biblioteca com arquivos fictícios](assets/screens/pt-BR/library.jpg)

## Arquivos e documentos

Importe um arquivo local ou crie um documento com um modelo disponível. O envio local não exige Google. A geração de documentos Google a partir de modelos depende do Drive central da instância; conectar seu Classroom pessoal não basta.

Escolha o modelo, preencha os campos, confira e crie. No modo **App**, a cópia fica no Drive central e o Hub permite visualizar/baixar PDF sem conceder nova permissão Google. No modo **Google Docs**, o proprietário é autorizado a editar o novo documento. Permissões Google existentes não são revogadas quando o Admin altera essa opção para documentos futuros.

Compartilhe os itens elegíveis com uma pessoa ou grupo pelo menu do item. Compartilhamento interno do Hub e permissões Google são camadas separadas. Compartilhar no Hub não concede automaticamente acesso arbitrário ao Google Drive.

## Projetos

Crie um projeto pessoal ou associe-o a uma disciplina. Abra o projeto, selecione uma pasta ou ZIP, confira as alterações propostas e envie a versão. O Hub guarda os arquivos; não executa código enviado. Valem as exclusões e limites mostrados na interface.

![Arquivos e versões de um projeto](assets/screens/pt-BR/project.jpg)

Projetos podem usar armazenamento local da instância ou o Drive administrado, conforme configuração e projeto. Confira o destino exibido. Um projeto local não é espelhado automaticamente no Drive.

O menu do projeto mostra as ações disponíveis, incluindo compartilhar, arquivar e excluir permanentemente para o proprietário. Arquivar mantém o projeto; excluir remove registros/arquivos e exige confirmação. Se o Drive recusar a exclusão, os registros locais são preservados para resolver a falha remota.

Quando arquivos remotos forem apagados ou não estiverem autorizados para este cliente OAuth, peça ao Admin para conferir [o armazenamento Drive](google.md). Não crie pastas duplicadas repetidamente para contornar falta de permissão.
