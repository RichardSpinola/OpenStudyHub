Excalidraw v0.18.1 fonts
========================

The font files in `public/excalidraw/fonts/` are copied without modification
from the [Excalidraw v0.18.1 font bundle](https://github.com/excalidraw/excalidraw/tree/v0.18.1/packages/excalidraw/fonts)
so the embedded editor works without a font CDN. Font authorship and license
notices are maintained in the corresponding upstream `index.ts` files. In
particular, Excalifont and Xiaolai identify the SIL Open Font License 1.1,
and Comic Shanns identifies the MIT License. The Excalidraw application
license is reproduced separately in `EXCALIDRAW-MIT.txt`.
